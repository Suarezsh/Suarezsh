## PROYECTOS DESTACADOS

**Asistencia con Deteccion de EPP** &nbsp;·&nbsp; `Python` `OpenCV` `YOLO` `face_recognition` `SQLite`
Sistema de control de asistencia que detecta en tiempo real si el personal usa equipos de proteccion personal. Identificacion facial integrada con base de datos local.

**ENOSA Energy Predictor** &nbsp;·&nbsp; `Python` `scikit-learn` `XGBoost` `Pandas` `Streamlit` `Plotly`
Herramienta de prediccion de consumo electrico. Modelos de regresion con XGBoost, visualizaciones interactivas y dashboard desplegado en Streamlit.

**SaludPlus IA Chatbot** &nbsp;·&nbsp; `FastAPI` `Groq API` `CSS`
Chatbot medico con FastAPI como backend y Groq (LLM) como motor de lenguaje. Orientacion en salud con respuestas rapidas y contextualizadas.

**RehabDrive** &nbsp;·&nbsp; `Python` `MediaPipe` `Google Gemini` `OpenCV` `pygame`
Sistema de rehabilitacion fisica que detecta posturas corporales con MediaPipe y retroalimenta al usuario con Gemini en tiempo real.

**Robot Laberinto IA** &nbsp;·&nbsp; `Python` `Q-learning` `A*` `tkinter`
Agente inteligente que aprende a resolver laberintos. Visualizacion del proceso de aprendizaje con Q-learning y A* en interfaz grafica interactiva.

**Sistema POS** &nbsp;·&nbsp; `PHP` `MySQL` `Tailwind CSS` `SQLite` `jsPDF`
Sistema de punto de venta con gestion de productos, ventas, reportes y exportacion de facturas en PDF. Interfaz moderna con Tailwind.

**Yachay Tea** &nbsp;·&nbsp; `HTML` `Vue.js` `Google Gemini` `Google APIs`
Plataforma educativa con asistente de IA integrado (Gemini), autenticacion con Google y mapas interactivos.

**djangoLibros** &nbsp;·&nbsp; `Django` `SQLite` `Python`
Sistema de gestion de biblioteca con autenticacion, panel de administracion y CRUD completo usando el ORM de Django.
